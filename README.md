## 📌 Visão Geral do Repositório

Este repositório reúne implementações desenvolvidas para fixação dos pilares fundamentais de **POO em Java**:
- **Encapsulamento**: criação de classes com atributos privados, métodos seletores (`getters`) e modificadores (`setters`).
- **Abstração & Modelagem de Domínio**: entidades reais representadas em software (contas bancárias, dormitórios, cartões de refeição, clubes).
- **Entrada e Saída de Dados (I/O)**: manipulação de arquivos de texto em Java com `Scanner` e `FileWriter`.
- **Algoritmos & Lógica Matemática**: cálculos estatísticos, desvio padrão e séries matemáticas.

## 📂 Mapa de Classes e Exercícios

| Classe / Arquivo | Descrição / Conceito Abordado |
| :--- | :--- |
| `Conta.java` & `ContaPrincipal.java` | Modelagem de conta bancária com depósitos, saques e validação de saldos |
| `Clube.java`, `ClubePrincipal.java`, `Membro.java` | Associação entre classes, arrays de objetos e gestão de sócios |
| `MealCard.java` | Controle de saldo e créditos para refeições estudantis |
| `Dorm.java` | Gestão de vagas e residentes em dormitório universitário |
| `Escrevendo1.java` | Gravação de dados em arquivo texto externo (`FileWriter`) |
| `Lendo1.java` | Leitura e parse de arquivos externos com tratamento de exceções |
| `DesvioPadrao.java` | Cálculo matemático de média e desvio padrão amostral |
| `ContaVogais.java` | Manipulação de cadeias de caracteres (`String`), vetores e contadores |
| `MascarasEmX.java` | Formatação de strings e manipulação de padrões |
| `Fibonacci.java` & `FibonnacciPrincipal.java` | Geração da sequência de Fibonacci de forma iterativa |
| `Fermi.java` | Implementação do jogo de adivinhação lógica Pico-Fermi-Bagel |

## 🚀 Como Compilar e Executar

Para compilar e executar qualquer uma das classes diretamente pelo terminal:

```bash
# Exemplo com a classe Conta
javac Conta.java
javac ContaPrincipal.java
java ContaPrincipal
```
